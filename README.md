# たした

話したこと・やったことを「ぽいっと」投げるだけで残す、個人専用のノート PWA です。
投げた文を「やった / 課題 / 芽」に自動分類し、勉強ノートのように分野ごとへ積み上げます。
判断・習慣化・通知・ログインを入口にしない設計で、気が向かない日でも投げれば残ります。

ロゴの「た」は、遠目で見ると「ナニ」に見えるよう崩したもじりです。

## ライブ URL

https://mentoce0-gif.github.io/kyouNANI/

## ホーム画面への追加

**iPhone (Safari)**

1. 上記 URL を Safari で開く
2. 共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選ぶ

**Android (Chrome)**

1. 上記 URL を Chrome で開く
2. 画面下に出る「追加」の案内をタップ、または右上のメニュー ⋮ から「アプリをインストール」を選ぶ

インストール後はスタンドアロン表示（ブラウザの UI 無し）で起動します。オフラインでも、投下・閲覧・分類・積む操作が可能です。

## データについて

- データは**この端末のブラウザ内**（localStorage）にのみ保存されます。サーバーには一切送信されません。
- ブラウザのデータを消去する、シークレット/プライベートモードで使う、別の端末やブラウザで開く、といった場合はデータを引き継げません。
- トラッキングや解析タグは入っていません。

## バックアップ方法

1. 右上の ⚙ から設定を開く
2. 「JSONを書き出す」でバックアップファイル（`tashita-YYYY-MM-DD.json`）をダウンロード
3. 復元するときは同じ画面の「JSONを読み込む」からファイルを選択
   - **追記マージ**: 今のデータに追加する
   - **置換**: 今のデータをすべて消して読み込んだ内容に差し替える
   - 読み込み前に件数を確認できます

定期的なリマインドはしません。設定画面の「最終バックアップ」表示を目安にしてください。

## ローカルでの開き方

ビルド不要の静的サイトです。リポジトリを取得して、任意の静的サーバーで配信してください。

```bash
git clone https://github.com/mentoce0-gif/kyouNANI.git
cd kyouNANI
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` を `file://` で直接開くと、Service Worker が動作しない場合があります。ローカルの静的サーバー経由での確認を推奨します。

## 使い方

1. 下の入力欄に、話したこと・やったこと・続きを書く（対応ブラウザではマイクからも入力可）
2. 「ぽい」で投げる
3. 改行や「。」「！」で自動的に文が分割され、種類（やった / 課題 / 芽）とカテゴリ（仕事 / 家庭 / 創作 / 生活 / その他）が付く
4. 「今日」で当日の記録を、「積む」で分野別に積み上がったノートを見る
5. 「課題」「全部」は必要なときだけ確認する
6. 「積む」画面のカテゴリごとに「束をコピー」でプレーンテキストとして書き出せる

分類はキーワード規則による自動判定です。誤分類はカードの「種類を変える」でいつでも直せます。

## 技術メモ

- ビルドツール・外部 CDN 依存なしの静的 PWA（HTML / CSS / Vanilla JS）
- Service Worker によりアプリシェルをキャッシュし、オフラインでも起動・閲覧・投下が可能
- 詳細な要件は [`要件定義.md`](./要件定義.md) を参照

# たした

積み重ねた時間が、かたちになる。個人専用の「あゆみ」ポートレート PWA です。
カテゴリごとに「＋30分」のように時間を足していくと、中央の光の糸玉が少しずつ育ち、輝きを増していきます。
ログインもサーバーもなく、記録はすべて自分の端末の中に残ります。

ロゴの「た」は、遠目で見ると「ナニ」に見えるよう崩したもじりです。

## ライブ URL

https://mentoce0-gif.github.io/kyouNANI/

## 使い方

- **＋ ◯◯を30分たす**: 直前に使ったカテゴリへ、ワンタップで30分を足します
- **他のカテゴリで足す**: カテゴリ名を自由に入力し、時間(15分/30分/60分、または任意の分数)を選んで足します
  - 既にあるカテゴリ名なら、そこに加算されます
  - 新しい名前なら、新しいカテゴリとして追加されます
- **最近の記録**: 足した記録の一覧です。「消す」で取り消せます(直後なら「元に戻す」も可能)
- **動きを止める**: 光の糸玉のアニメーションを止めたり、再開したりします。OSで「視差効果を減らす」を有効にしていると、止まった状態で始まります

画面に表示されるもの:

| 表示 | 内容 |
| --- | --- |
| 積み重ねた時間 | これまでに足した時間の合計 |
| これまでの「やった」 | 足した回数 |
| 直近7日間 | 過去7日間に足した時間の合計 |
| 今週は◯日、記録がありました | 過去7日間で記録した日数 |
| カテゴリの帯と凡例 | 合計時間に占める各カテゴリの割合 |

## 光の糸玉について

中央の立体は、球面を編むように巡る5本の光の糸です。

- 糸ごとにうねりの位相や振幅がずれたリズムで変わり続けるので、同じ姿には戻りません。開くたびに違う姿から始まります
- 始めたばかりの頃は、太い糸は1本だけです。時間を積み重ねるほど糸が1本ずつ太くなり、色の鮮やかさと発光が強まります(約64時間で5本すべてが太くなります)

## ホーム画面への追加

**iPhone (Safari)**

1. 上記 URL を Safari で開く
2. 共有ボタン(□に↑)をタップ
3. 「ホーム画面に追加」を選ぶ

**Android (Chrome)**

1. 上記 URL を Chrome で開く
2. 画面下の「追加」をタップ、または右上のメニュー ⋮ から「アプリをインストール」を選ぶ

追加後はブラウザの枠のないアプリとして起動し、オフラインでも使えます。

## アップデート

新しい版が公開されると、アプリを開いたときや前面に戻したときに、画面下部に「新しい版があります」と表示されます。「再読み込み」を押すと切り替わります。

表示されない場合は、アプリを上にスワイプして完全に終了し、しばらくしてから開き直してください。

## データとバックアップ

- 記録は**この端末のブラウザ内**(localStorage)にだけ保存され、外部には一切送信されません。トラッキングや解析タグもありません
- ブラウザのデータ消去、プライベートモードでの利用、別の端末やブラウザで開いた場合は、記録を引き継げません

バックアップは右上の ⚙ から行います。

1. 「JSONを書き出す」でファイル(`tashita-YYYY-MM-DD.json`)を保存
2. 復元するときは「JSONを読み込む」でファイルを選ぶ
   - **追記マージ**: 今の記録に追加する
   - **置換**: 今の記録をすべて消して、ファイルの内容に差し替える
   - 読み込み前に件数を確認できます

定期的なリマインドはありません。設定画面の「最終バックアップ」の日時を目安にしてください。

## ローカルでの開き方

ビルド不要の静的サイトです。

```bash
git clone https://github.com/mentoce0-gif/kyouNANI.git
cd kyouNANI
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` を `file://` で直接開くと Service Worker が動かないため、静的サーバー経由で開いてください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `css/style.css` | スタイル(ダーク基調、OSがライトなら自動切替) |
| `js/app.js` | 記録・集計・画面描画・バックアップ・更新通知 |
| `js/scene.js` | 光の糸玉の描画(外部ライブラリを使わない素の WebGL) |
| `sw.js` | オフライン用キャッシュと更新の取り込み |
| `manifest.json` / `icons/` | ホーム画面追加用の設定とアイコン |

公開する変更を入れたときは、`sw.js` の `CACHE_NAME` と `js/app.js` の `APP_VERSION` を上げてください。上げないと、インストール済みのアプリに更新が届きません。

最初の構想は [`要件定義.md`](./要件定義.md)(「ぽいっと記録」)にあります。現在の「私のあゆみ」は、そこから方向転換したものです。
